# 📊 React CRM System

Современное веб-приложение CRM-системы для управления клиентами, заявками и рабочими процессами, разработанное на React и TypeScript.

## 🛠 Стек технологий

* **Core:** React, TypeScript
* **Сборка и инструменты:** Vite, ESLint, npm
* **Стилизация:** CSS3 / HTML5 (адаптивный интерфейс)
* **Контроль версий:** Git & GitHub

## ✨ Основной функционал

* Просмотр, добавление, редактирование и удаление записей (CRUD-операции)
* Удобная фильтрация, поиск и сортировка данных
* Строгая типизация компонентов, пропсов и состояния с помощью TypeScript
* Компонентная архитектура и быстрая сборка через Vite

## 🚀 Как запустить проект локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку проекта и установите зависимости:
   ```bash
   cd React-CRM
   npm install
   ```
3. Запустите локальный сервер для разработки:
   ```bash
   npm run dev
   ```
